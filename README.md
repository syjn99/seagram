# The Seagram Building — A Scrolling Architectural History

Interactive scrollytelling timeline presenting the history of the Seagram Building (375 Park Avenue, NYC), from the 1916 zoning law through Mies van der Rohe's radical design to its present-day weathering.

## Tech Stack

Vite + React 18 + TypeScript, Tailwind CSS v4, GSAP ScrollTrigger, Motion

## Development

```sh
npm install
npm run dev
```
